# GEO 定词 / Query Set 方法论（v4.5 引入）

> 来源：巴拉巴拉案定词实战共创梳理，2026-08 沉淀为本技能的定词层标准。
> 本文件是 Phase 3（链路地图与策略方向）的定词层规范：方向是骨架，Query Set 是肌肉——方向再对，词没人味、AI 没槽位、品牌没证据，就是哑弹。
> 巴拉巴拉案例只用于展示方法，不作为其他品牌的固定模板。

---

## 1. 核心判断

GEO 定词不是把 SEO 关键词拉长，也不是把品牌传播支柱改写成问句。一个有效的 Query 必须同时满足三件事：

1. **消费者会自然问**：像真实用户说话，而不是品牌部、咨询顾问或传播方案的语言。
2. **AI 有位置放品牌**：答案结构会自然进入品牌推荐、比较、验证或购买选择，而不是只输出知识。
3. **品牌有证据可答**：品牌能用真实、可验证的 Reason to Believe（RTB）进入答案，而不是依靠空泛口号硬占位。

因此，定词的最小闭环是：

> **真实消费问题 × 品牌可触发 × 品牌可证实**

缺少任意一项，都不应进入核心 Query Set。

## 2. Query 的品牌可触发原则

### 2.1 什么是“品牌可触发”

“品牌可触发”是指：在不预埋目标品牌名的情况下，Query 的问题结构会促使 AI 自然列出、比较或推荐品牌，形成一个可竞争的品牌槽位。

对比：

| Query | 常见答案结构 | 是否适合作为核心词 |
|---|---|---|
| 儿童日常穿搭推荐 | 搭配公式、颜色和单品建议 | 否，通常没有品牌槽位 |
| 儿童日常穿搭品牌推荐 | 列出品牌并说明适配理由 | 是 |
| 童装 A 类是什么意思 | 标准科普 | 否，除非用于教育内容副词池 |
| A 类童装品牌推荐 | 品牌推荐 + 标准解释 | 是 |
| 儿童友好是什么意思 | 概念解释 | 否 |
| 真正尊重孩子审美的童装品牌有哪些 | 品牌推荐 + 价值判断 | 可用，但必须验证真实口吻与 BTR |

### 2.2 Brand Trigger Rate（BTR）

Brand Trigger Rate 衡量的是“这个问题会不会触发品牌答案”，不是“目标品牌有没有被提到”。

**Query 级 BTR：**

```text
BTR(q) = 出现至少一个具体品牌的有效回答次数 / 该 Query 的有效测试次数
```

**Query Set 级 BTR：**

```text
BTR(set) = 通过品牌触发阈值的 Query 数 / Query 总数
```

测试时应固定平台、模型版本、地区、日期和提问方式；在多个核心平台各测试至少一次，重要 Query 可重复测试以观察波动。若无法进行多次测试，明确标注为“小样本预检”，不要伪装成稳定统计结论。

### 2.3 BTR 与品牌结果指标必须分开

| 指标 | 回答的问题 |
|---|---|
| **BTR** | 这个 Query 会不会列品牌？ |
| **目标品牌提及率** | 列品牌时，有没有目标品牌？ |
| **推荐入选率** | 目标品牌是否以候选/推荐身份出现？ |
| **首推率** | 目标品牌是否成为第一推荐？ |
| **RTB 渗透率** | AI 是否说出了品牌希望被理解的选择理由？ |

BTR 高但目标品牌提及率低，说明这是一个值得抢、但尚未占领的战场。BTR 低则说明问题本身可能不适合用来做推荐抢位。

### 2.4 品牌可触发的快速改写法

- 在纯知识问法中加入“品牌推荐 / 哪个牌子 / 怎么选 / 哪个更适合”。
- 在纯场景问法中加入明确品类和选择动作。
- 在抽象价值问法中加入具体矛盾、人群或使用场景。
- 若改写后仍像品牌方造词，删除，不强救。

## 3. 五类核心决策意图

核心 Query Set 优先保留与选择行为直接相关的五类意图。

| 意图 | 消费者任务 | 常用句式 | 主要 GEO 价值 |
|---|---|---|---|
| **推荐意图** | 建立候选集 | 哪个牌子好 / 有哪些品牌推荐 | 扩大非品牌词曝光，进入 shortlist |
| **比较意图** | 在候选中取舍 | A 和 B 哪个好 / 怎么选 | 竞品截流，建立差异理由 |
| **购买决策意图** | 降低下单不确定性 | 值不值得买 / 适不适合 / 这个价位选谁 | 推动选择和转化 |
| **场景意图** | 在具体生活情境中找解决方案 | 上学、旅行、户外、生日、送礼时选什么 | 把品牌放入真实决策现场 |
| **品牌验证意图** | 验证已知品牌 | 靠谱吗 / 什么档次 / 质量怎么样 / 国外有店吗 | 校准认知、修复疑虑、补充信任 |

筛选时不要把五类意图平均配额。应根据品类决策方式、品牌阶段和业务目标分配权重：成熟消费品牌通常以推荐、场景、比较和验证为主；高风险或高客单品类会提高购买决策与验证意图权重。

## 4. 两阶段：从知道到入选、从入选到偏爱

两阶段按消费者心智结果划分，不按内容发布时间、品牌词/非品牌词或“先铺量后优化”划分。

### Phase 1｜从知道到入选

目标：让品牌进入候选集，建立“优先被推荐”的基础盘。

典型消费者问题：

- **大不大？** 品牌是否属于第一梯队，规模和行业地位如何。
- **靠不靠谱？** 品质、安全、稳定性和售后是否可信。
- **适不适合？** 是否适合特定人群、产品需求和使用场景。
- **什么水平？** 价格带、档次、专业度、全球化或行业能力处于什么位置。

核心指标：品牌认知准确率、推荐入选率、非品牌 Query 提及率、关键场景覆盖率。

### Phase 2｜从入选到偏爱

目标：在品牌已经进入候选集后，形成竞品难以替代的选择理由。

典型消费者问题：

- 为什么它更适合“我 / 我的孩子 / 我的家庭”？
- 使用者为什么喜欢，购买决策者为什么愿意买？
- 在功能和价格接近时，它凭什么成为优先选择？
- 哪些品牌价值能被消费者转译成切身利益或身份认同？

核心指标：首推率、竞品比较胜率、独特 RTB 渗透率、偏爱理由一致性。

### 两阶段的权重原则

Phase 1 通常承担更大的 Query 盘，因为它覆盖广泛的推荐、验证和场景选择。Phase 2 应少而精：它的任务不是围绕品牌理念造几十个问法，而是在少量高价值选择问题下建立独特 reason to choose。

## 5. 品牌资产到 Query 的四层转译

### 5.1 标准转译链

```text
品牌资产
  ↓ 这项资产为消费者解决什么不确定性？
消费者问题
  ↓ 消费者会如何自然地向 AI 提问？
Query
  ↓ 品牌凭什么出现在答案里？
Reason to Believe
```

每个 Query 都要能沿链路向前追溯、向后落证据。

### 5.2 四层定义

| 层级 | 关键问题 | 输出要求 |
|---|---|---|
| **品牌资产** | 品牌有什么真实、独特、可持续的能力或事实？ | 规模、产品、供应链、渠道、研发、用户洞察、服务、文化资产等 |
| **消费者问题** | 它降低了消费者的哪一种疑虑或满足了哪一种选择需求？ | 用消费者语言描述，不使用品牌内部术语 |
| **Query** | 用户会怎么问 AI，且答案会出现品牌吗？ | 通过自然度与 BTR 预检 |
| **RTB** | 品牌凭什么被推荐？ | 可核验事实、数据、产品能力、第三方证据、真实案例 |

### 5.3 转译示例

| 品牌资产 | 消费者问题 | Query | RTB |
|---|---|---|---|
| 覆盖多年龄段、多场景产品 | 想一次解决孩子不同场合穿衣，不想反复换品牌 | 既适合上学又适合聚会的童装品牌有哪些 | 年龄段覆盖、场景产品线、具体产品与用户评价 |
| 海外本地化经营 | 这个中国品牌是不是只靠低价，品质和经营能力到什么水平 | 哪些中国童装品牌已经进入欧洲市场 | 本地门店、渠道、标准适配、供应链与公开经营事实 |
| 长期儿童洞察内容 | 品牌是否真的理解孩子，不把孩子当缩小版成人 | 不想让女孩穿得太成人化，有什么童装品牌 | 年龄适配设计、儿童研究、产品案例、长期内容资产 |
| 公益/儿童友好项目 | 品牌是否真正关注儿童成长 | 哪些童装品牌比较关注儿童成长 | 公益与儿童友好项目作为回答证据，而非把“社会责任”硬造为母题 |

### 5.4 必须避免的倒置

错误路径：

> 品牌有 ESG 战略 → 生成“有社会责任感的品牌有哪些”

正确路径：

> 品牌有 ESG 资产 → 判断它解决的真实消费问题 → 若消费者不会直接问 ESG，则把 ESG 降为 RTB，支撑“为什么值得信任 / 为什么值得喜欢”

## 6. 伪命题识别：科普词、ESG 与品牌方自嗨

### 6.1 三类常见伪命题

1. **纯科普词**：消费者要的是知识，不是品牌。如“童装 A 类是什么意思”“儿童冲锋衣怎么洗”。
2. **品牌方价值词**：语言成立，但消费者不会自然这样问。如“有情怀的童装品牌”“践行长期主义的品牌”。
3. **ESG/公益直译词**：品牌有资产，不代表它是核心购买母题。如“最有社会责任感的童装品牌”。

### 6.2 处理规则

| 情况 | 处理 |
|---|---|
| 问题高频但不触发品牌 | 放入内容教育/FAQ 副词池，不计入核心推荐 Query Set |
| 问题能改写成自然选择问法 | 改写后做 BTR 预检 |
| 资产重要但消费者不直接问 | 降为 RTB、品牌事实库或声誉监测项 |
| 只有品牌方认为重要，找不到消费者问题 | 暂不纳入，不为补齐策略柱子造词 |

### 6.3 一票否决问题

候选 Query 出现以下任一情况，应删除或重写：

- AI 回答天然只讲知识、技巧、概念或搭配，不列品牌。
- 用户需要知道品牌官方术语，才可能说出这个问法。
- Query 只是把品牌主张后面加上“有哪些”。
- 品牌没有真实证据承接，只有口号。
- 为了让六个方向词数相等而制造低自然度长尾。

## 7. 同义语义簇管理

### 7.1 为什么按簇管理

“童装哪个牌子好”“童装品牌推荐”“儿童服装哪个品牌靠谱”可能属于同一稳定意图。若把它们当作三个独立战场，会虚增覆盖率、测试量和内容量。

应以**一个消费者任务**定义一个语义簇（Semantic Cluster），句式只是簇内变体。

### 7.2 簇结构

每个语义簇至少包含：

- `Cluster ID`：稳定编号。
- `核心意图`：消费者要完成的任务。
- `代表 Query`：最自然、最能触发品牌的标准问法。
- `短词变体`：适合扫描和对客展示。
- `长尾变体`：加入人群、场景、限制和情绪。
- `意图类型`：推荐 / 比较 / 购买决策 / 场景 / 品牌验证。
- `阶段`：从知道到入选 / 从入选到偏爱。
- `RTB`：品牌能承接的证据。

### 7.3 去重规则

- 只换“哪个 / 什么 / 有哪些”而消费者任务不变：同一簇。
- 增加人群或场景但选择标准未改变：通常作为簇内变体。
- 决策任务改变，例如从“品牌推荐”变为“A/B 比较”：拆为新簇。
- 答案需要调用不同 RTB：优先拆簇。
- 覆盖度按语义簇计算；问法数量只表示测试深度，不表示战略覆盖。

### 7.4 表格呈现规则

对客表格中，同一语义的词放在同一行；不同语义拆行。深度执行表可一条 Query 一行，但必须保留 Cluster ID，防止同义词被误算为多个节点。

## 8. 场景词设计

### 8.1 场景词不是“场景 + 穿搭”

纯场景内容容易让 AI 输出教程。有效场景 Query 要把用户带到选择动作：

```text
人群/对象 + 具体场景 + 约束或矛盾 + 品牌/品类推荐槽位
```

例如：

- 儿童日常穿搭推荐 → **儿童日常穿搭品牌推荐**
- 儿童生日穿什么 → **儿童生日穿什么品牌，平时也能穿**
- 大童女装推荐 → **10 岁女孩不幼稚又不过分成熟的童装品牌**

### 8.2 好场景的四个来源

1. **时间节点**：开学、换季、春节、生日、旅行。
2. **生活任务**：上学、户外、运动、聚会、送礼、通勤。
3. **人群变化**：新手父母、婴幼儿、中大童、高瘦/偏胖、敏感肌。
4. **真实矛盾**：好看与实穿、孩子喜欢与家长得体、特殊场合与日常复用、品质与价格。

### 8.3 场景词质量判断

- 场景是否发生在真实生活，而不是传播主题。
- 用户是否面临一个具体选择或矛盾。
- AI 是否会自然列出品牌或产品。
- 品牌是否有对应产品与证据，不把“全场景”写成空泛覆盖。

## 9. Query Set 生产流程与表结构

### 9.1 八步流程

1. **确定业务目标**：认知校准、推荐抢位、竞品截流、声誉修复或转化支持。
2. **收集真实问题**：VOC、客服、评论、站内搜索、销售问答、社媒讨论、搜索建议、AI 对话记录。
3. **盘点品牌资产**：区分独特资产、行业通用门槛和未被验证的传播主张。
4. **完成四层转译**：品牌资产 → 消费者问题 → Query → RTB。
5. **按五类意图生成候选词**：推荐、比较、购买决策、场景、品牌验证。
6. **做品牌可触发预检**：测试 BTR，删除只出知识不出品牌的问法。
7. **建立语义簇并去重**：选代表 Query，保留变体，不虚增覆盖。
8. **分阶段、定优先级并建基线**：映射两阶段，设置 P0/P1/P2，记录当前 AI 答案与品牌占位。

### 9.2 推荐工作表字段

| 字段 | 说明 |
|---|---|
| Cluster ID | 语义簇编号 |
| 阶段 | 从知道到入选 / 从入选到偏爱 |
| 战略方向 | 对应品牌未来战略与 GEO 心智目标 |
| 消费者问题 | 非品牌内部语言的真实问题 |
| 代表 Query | 该簇标准问法 |
| Query 变体 | 短词、长尾、人群、场景、情绪变体 |
| 意图类型 | 五类核心意图之一 |
| BTR | 品牌可触发预检结果 |
| 目标品牌占位 | 未提及 / 提及 / 入选 / 首推 / 错误描述 |
| 主要竞品 | 当前回答中的竞争品牌 |
| RTB | 品牌承接答案的证据 |
| 优先级 | P0 / P1 / P2 |
| 信源与内容动作 | 需要建设或修正的内容节点 |
| 测试信息 | 平台、模型、日期、地区、轮次 |

### 9.3 权重规则

Query 权重应来自以下证据，而不是平均分配：

- VOC / 客服 / 站内搜索中的问题密度。
- 该问题离品牌选择和购买决策的距离。
- BTR 与目标品牌当前缺位程度。
- 品牌是否拥有独特、可信的 RTB。
- 业务优先级、品类利润或重点市场。

没有公开 AI 搜索量时，只能写“策略权重”或“测试优先级”，不能写“真实流量占比”。

## 10. 指标体系：品牌认知校准与推荐抢位

### 10.1 输入层：Query 质量

| 指标 | 定义 |
|---|---|
| **Brand Trigger Rate** | 回答中出现至少一个具体品牌的比例 |
| **自然口吻通过率** | 经 VOC 对照或人工评审后，像真实消费者问法的 Query 占比 |
| **决策接近度** | Query 与候选建立、比较、验证或购买选择的接近程度 |
| **RTB 可承接率** | 有真实品牌证据可回答的 Query 占比 |
| **语义簇去重率** | 去除同义重复后保留的有效语义簇比例，用于识别虚胖词表 |

### 10.2 认知校准层

| 指标 | 定义 |
|---|---|
| **品牌认知准确率** | AI 对品牌定位、品类、目标人群、产品和经营事实描述准确的回答占比 |
| **核心信息覆盖率** | 预设核心认知锚点被正确表达的比例 |
| **错误/过时信息率** | 含事实错误、过时信息或混淆描述的回答占比 |
| **品牌定义一致性** | 不同平台对品牌的核心定义是否稳定一致 |
| **品牌验证通过率** | 在“靠谱吗 / 什么水平 / 值得买吗”等验证词中得到正向、准确回答的比例 |

### 10.3 推荐抢位层

| 指标 | 定义 |
|---|---|
| **目标品牌提及率** | 目标品牌在全部有效回答中出现的比例 |
| **推荐入选率** | 目标品牌以推荐候选身份进入答案的比例 |
| **Top 3 推荐率** | 目标品牌位列前三推荐的比例 |
| **首推率** | 目标品牌成为第一推荐的比例 |
| **竞品比较胜率** | 在指定 A/B 或多品牌比较标准下，目标品牌获得更优结论的比例 |
| **关键场景占位率** | 目标品牌在 P0 场景语义簇中入选的比例 |
| **RTB 渗透率** | 推荐目标品牌时，答案同时说出至少一项目标 RTB 的比例 |

### 10.4 两阶段指标映射

| 阶段 | 主指标 | 辅指标 |
|---|---|---|
| 从知道到入选 | 品牌认知准确率、推荐入选率、关键场景占位率 | 提及率、Top 3 推荐率、错误信息率 |
| 从入选到偏爱 | 首推率、竞品比较胜率、独特 RTB 渗透率 | 偏爱理由一致性、品牌验证通过率 |

### 10.5 测量纪律

- 固定 Query、平台、模型、地区、日期和新会话条件。
- 区分“被提及”“被推荐”“被首推”“被正确解释”。
- 保存原始回答与引用信源，不能只保留评分。
- 对生成波动大的 Query 重复测试，并报告样本量。
- 指标反映的是约定测试框架下的 AI 回答表现，不等于全网真实用户搜索量或销售归因。

## 11. 巴拉巴拉案例演示

本案例展示如何使用方法，不代表其他品牌应复制六个方向。

### 11.1 两阶段六方向

| 阶段 | 方向 | 消费者问题 | 示例 Query | 主要 RTB |
|---|---|---|---|---|
| 从知道到入选 | 行业领导力 | 这么多童装品牌，哪些属于第一梯队 | 中国一线童装品牌有哪些 | 市场地位、规模、渠道、年龄段覆盖 |
| 从知道到入选 | 品质安全信任 | 给孩子买是否可靠、安心 | 儿童衣服哪个牌子质量靠谱 | 产品标准、检测、质量体系、公开经营事实 |
| 从知道到入选 | 儿童生活场景力 | 什么情况下选它最合适 | 既适合上学又适合聚会的童装品牌有哪些 | 日常、户外、高光时刻等产品与场景证据 |
| 从知道到入选 | 全球化实力 | 中国品牌到了什么水平 | 哪些中国童装品牌已经进入欧洲市场 | 海外经营、本地化、市场与标准适配事实 |
| 从入选到偏爱 | 儿童成长价值 | 孩子为什么会喜欢、品牌是否理解孩子 | 不想让女孩穿得太成人化，有什么童装品牌 | 儿童洞察、年龄适配设计、《中国小朋友》等长期资产 |
| 从入选到偏爱 | 家庭生活方式 | 孩子喜欢与家长愿意买能否兼顾 | 妈妈和孩子都喜欢的童装品牌有哪些 | 好看与实穿、日常与高光、家庭共同决策证据 |

### 11.2 ESG 的正确位置

“儿童友好联盟、公益、环保材料”等可以是重要品牌资产，但不自动成为 Query 方向。若消费者不会自然问“最有社会责任感的童装品牌”，就应把这些资产作为“真正关注儿童成长”“为什么值得信任或喜欢”的 RTB。

### 11.3 场景词的关键改写

```text
儿童轻户外穿搭
→ 儿童轻户外品牌推荐

儿童节穿搭推荐
→ 儿童节童装品牌推荐

儿童生日穿什么
→ 儿童生日穿什么品牌，平时也能穿
```

增加的不是几个字，而是一个可被品牌竞争的答案槽位。

## 12. 交付前检查清单

### 消费者真实性

- [ ] Query 是否像消费者原话，而不是品牌或咨询语言？
- [ ] 是否有 VOC、客服、站内搜索、社媒讨论或其他真实问题来源？
- [ ] 是否避免为补齐方向而平均造词？

### 品牌可触发

- [ ] AI 回答是否会自然列出或比较品牌？
- [ ] 是否记录 BTR，并与目标品牌提及率分开？
- [ ] 纯科普/纯穿搭词是否已改写、降级或删除？

### 转译与证据

- [ ] 每个 Query 是否可回溯到消费者问题？
- [ ] 每个 Query 是否有真实 RTB 可承接？
- [ ] ESG、公益、理念是否在必要时降为证据层？

### 结构与去重

- [ ] 是否覆盖推荐、比较、购买决策、场景、品牌验证五类核心意图？
- [ ] 是否按“从知道到入选 / 从入选到偏爱”分层？
- [ ] 是否使用 Cluster ID 管理同义语义簇？
- [ ] 覆盖率是否按语义簇而非句子数计算？

### 指标与边界

- [ ] 是否同时设置品牌认知校准与推荐抢位指标？
- [ ] 是否区分提及、入选、Top 3、首推与 RTB 渗透？
- [ ] 是否保留平台、模型、日期、地区和样本量？
- [ ] 是否避免把策略权重或短词数量宣称为真实搜索量？
