# geo-strategy-init

GEO（Generative Engine Optimization，生成式引擎优化）品牌策略初始化技能。一套从品牌调研到 GEO 策略输出的结构化工作流，适用于 AI 搜索时代的品牌可见度诊断与占位策略制定。

## 核心逻辑

GEO 不是「生产内容等 AI 引用」，而是：

> 扫描 AI 当前怎么回答 → 识别品牌缺位节点 → 定向生产内容修正/占位

GEO 也不是关键词优化，而是**消费者意图在 AI 世界的重新表达**。策略必须面向未来——锚定品牌近期的战略信号（官方发声、高管发言、财报管理层讨论），而不是总结品牌过去的产品实践。

## 工作流

```
Pre-Phase: 策略定位问卷（必做）
Phase 0:   AI 回答现状扫描（三层意图：疑虑层 / 品类层 / 品牌层）
Phase 1:   品牌深度调研（九大模块，模块九「战略前瞻」是策略方向的唯一锚点）
Phase 2:   GEO 机会诊断（可见性 / 信息准确性 / 竞品对比 / 声誉风险 / 战略缺位）
Phase 3:   搜索链路地图与策略方向生成（含定词层规范与示例词质量红线）
Phase 4:   策略文档输出
```

## 关键原则

- **前瞻性**：方向命名格式为「未来战略方向 → GEO 心智目标」，禁止「已有产品线 → 产品覆盖」
- **定词最小闭环**：真实消费问题 × 品牌可触发 × 品牌可证实（RTB），缺一不进词表
- **平台选择有据可依**：不做全平台覆盖，选 2–3 个核心平台深耕，其余跟随覆盖
- **业务模式必查**：含加盟/招商模型的品牌，方向清单必须含 B 端招商方向
- **边界声明**：承诺「搜索链路覆盖度」和「内容占位策略」，不承诺 AI 引用效果

## 适用场景

品牌 GEO 策略制定、GEO 研判、AI 搜索优化方向规划、品牌调研与诊断、对客 GEO 初步沟通方案。
